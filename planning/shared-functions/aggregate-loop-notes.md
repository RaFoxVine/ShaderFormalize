# 矩阵、数组与循环：后续实现调查（Outlined，无代码授权）

这份记录服务后续language切片规划，尚非Ready计划。先完成共享函数和copyback，再依据实际接口细化；不新增用户决策或宣称已支持这些语法。

## 实际DXC证据

`artifacts/language-probes/aggregate.hlsl/.ast.txt`包含out/inout/默认参数、局部float2x2、mul、固定数组和uint for循环；`matrix.hlsl/.ast.txt`包含cbuffer矩阵/数组、动态行索引、双下标写入和矩阵helper参数。两份原始输入均由固定DXC成功编译。

矩阵行/向量元素下标由DXC表示为CXXOperatorCallExpr，callee为确切CXXMethod `operator[]`，不是普通ArraySubscriptExpr。普通数组下标是ArraySubscriptExpr。矩阵类型既有float2x2别名，也有matrix<float,2,2>规范拼写；所有类型与调用重载都应使用DXC元数据，不重解析HLSL源码。for有初始化、Null条件变量、比较、递增、body五个明确槽位。

## Aggregate表示的候选方向

逻辑矩阵按行、固定数组按元素组织成有明确源类型/形状的不可变复合值；可复用record的叶遍历/共享函数形参/返回/选择，但须保留矩阵与数组种类及源形状，不能把维度或逻辑行列混同于cbuffer物理布局。普通矩阵`*`的分量乘与`mul`的矩阵乘必须分别建模；mul结果维度按DXC已选重载验证。矩阵数学可按有限求和或展开成现有实数运算，无需浮点编码。

需要一个shared地址层统一整变量、字段、矩阵行/元素、数组元素与向量分量；读写都使用快照索引。动态读取用完整字段选择，写回以逐元素条件更新保存原值。越界是实际执行域义务，仍放最终结论，不能模N后无声接受。copy-out两个动态地址不能证明不重叠时拒绝，不能猜索引相等与否；静态不同元素应接受。部分初始化必须逐叶跟踪，禁止把未写值自动补零。DXC明确给出的初始化填充值需单独检查真实AST。

cbuffer解析当前硬编码width，必须与新类型注册/叶布局一起调整；先从typed AST取得字段逻辑形状，再构造数学输入。核心接口比较仍检查完整源声明与布局，不能因未使用字段而放弃一致性。输入范围选择器需要能指到矩阵行/数组元素；普通旧输入和证明保留。尚需决定并审阅具体上限、stage复合语义、数组参数/返回的确切DXC形式及所有消费者。

## 终止循环的候选方向

首选明确计数循环`for (uint i=start; i<bound; ++i)`：要求start/bound是可确认不随位置变化的纯值，body不改计数器或边界；先支持常量及由uniform纯运算得到的边界。用数学步数`bound.toNat-start.toNat`精确迭代，单步i<bound保证不会发生uint回绕；不是任意fuel运行到上限。常量小循环可以完全展开，未知计数用Nat递归/迭代定义保留共享body，不能将最大2^32次复制进Lean文本。

每步传完整局部状态字段、实际入口与alive，返回更新状态/存活/域；状态只在该步实际位置推进，Ops继续收到完整字段和实际执行mask。域按步合取。循环体适合编译为共享内部函数，但函数/循环定义之间必须有统一拓扑依赖，不能出现生成次序或模型JSON环。loop结果及语义模块必须进入目标与审计哈希。

varying次数、break/continue/return、while/do、<=终止与非单位步长尚未Ready；不能悄悄套用上述计数证明。特别是varying次数会影响跨位置字段与导数上下文，不能拿每个位置独立执行的数值循环替代现有整场语义。尚需真实DXC、形式单步/归纳与组合Shader证据，然后独立P确定可执行范围。
