# 首个源码—Lean—Unity 闭环

日期：2026-10-24。用户授权：先跑通，不再等待完整方案人工审阅；工具与缓存放当前工作目录，Unity 指定工程可修改；依赖应可复现，暂不要求拆离 Unity 工程。

## 结果与边界

交付命令行原型：输入两份受支持的 HLSL、共同输入范围，调用固定 DXC 提取带类型 AST，确定性转换为小型数学表达式，自动生成 Lean 定义和命题，再由 agent 写证明、Lean 检查。Unity 对相同文件编译并执行数值用例。首对输入是 `lerp(a,b,saturate(t))` 和 `a+(b-a)*t`，其中 a、b 为 float4，t 为 float，条件 0≤t≤1。

当前选择 HLSL/DXC 是为了已有带类型函数体入口，不是锁定整个产品语言。Slang 的本机调试导出不足，后续可换前端。首版公开支持范围刻意小：单入口、仅参数输入、一个 return 表达式、float/float4、加减乘/一元负号、括号、精确数字字面量、lerp/saturate、编译器隐式标量广播。其他类型、语句、资源、用户函数、除法、循环、分支、导数、纹理等明确返回不支持；这些后续能力没有在本次闭环中冒充已完成。

## 实现职责

- `tools/` 的 Python 标准库工具负责受限 DXC 调试 AST 适配、检查与生成。固定二进制 SHA256，AST 树节点完整消费，未知节点/转换/引用拒绝；不建立通用 HLSL 解析器。来源文本用于恢复数字原始文字，不能将 AST 已舍入数值再次当成精确字面量；宏或位置不明确时拒绝。
- 参数的类型、顺序、名称、semantic 和输出 semantic 必须一致。只接受 main，禁止外部用户函数伪装为 lerp/saturate；拒绝无语义依据的隐式转换。数学 IR 使用 Real，向量用四个实数分量。
- `proof/` 的受版本管理 Lean 语义定义解释数学表达式。生成定义与目标写入生成目录，证明脚本由 agent 维护在源码中；检查器使用 Lean 验证生成目标和该脚本，检查未完成证明与额外公理，不把日志退出 0 等同于证明成功。数学定义对应实际输入源码，报告源/模型/证明哈希。
- `examples/lerp/` 存原始、整理后源码与输入约束。证明覆盖任意实数 a、b 与范围内 t。
- `unity/` 的 C# 运行脚本通过既有 CLI eval_file 运行，创建隔离的临时 Shader/材质/线性浮点 RenderTexture，使用同样输入函数，读取 GPU 输出，与另一侧及 CPU 公式比较；包含范围端点、多个 t 和颜色组合。所有 UnityEngine 临时对象在 finally 销毁，恢复 RenderTexture.active。不修改现有场景；必要包装/输出放 Assets/ShaderFormalizeProbe（后续可清理）。报告明确 GPU 是有限样本和浮点容差测试。
- 可复现启动脚本只在 `.tools/` 安装官方 Lean/DXC 归档并验证 SHA256；Lake 的清单固定 mathlib 和传递依赖 Git revision，下载缓存、包和产物都在当前 repo 下。使用 Lake 自带依赖锁而不是额外嵌套 submodule；文档解释这个决定。

## 失败与验证

输入错误/不支持/尚未证明/已证明明确分开。不能自动缩小输入范围；范围需要一致且可满足。证明不通过不能宣称不等价。实现一个错误优化、范围外差异和未知语法的负例，保证它们不能得到已证明。至少回归数字文字、参数不匹配、用户函数冒名、未知节点、变更后证明失效、旧报告不重用等实际风险。

验收：固定工具本地安装；真实源码提取和生成；Lean 对目标无 sorry 的检查；正例通过；错误优化不能通过；Unity 实际编译和 GPU 回读通过，非空样本与最大误差可见；干净依赖管理和复现说明。独立 P 审方案，初验后独立 Q 审真实 diff 和证据；问题在授权范围内修复。

独立 P 已完成并通过（plan_review）。落实的检查细节：checker 单独生成 `example : Generated.expected := AgentProof.equivalent` 一类目标绑定模块，以完全限定名绑定实际生成命题；检查绑定定理的传递公理，仅允许 Lean 常用逻辑公理，不接受自定义 axiom 或 sorryAx。仅源码证明脚本编译成功不够。约束首版仅接受 t 的闭区间，端点是精确十进制有理数，拒绝未知字段、矛盾区间与不适用约束。显式设置本地 MATHLIB_CACHE_DIR，预置并记录 leantar 0.1.15 校验；固定 DXC 安装后先 smoke，不能回落到 PATH。Unity 结果必须含实际源码哈希、非空样本与有限误差。
