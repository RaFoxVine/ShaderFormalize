# 固定次数循环与组合材质

`--frontend shared`支持能在导入时确定次数的普通uint循环，例如`for (uint i = 0u; i < 2u; ++i)`。DXC先负责语法、类型、作用域及调用解析；转换器再核对计数器身份和终止条件，将确切的每次迭代转换成已有数学计算。没有运行到任意次数便截断的机制。

起点和上界必须是纯uint常量表达式，采用精确uint32运算，包括回绕；常量移位仍须小于32。实际次数是`max(end-start,0)`，单个循环最多64次。只接受独立声明的uint计数器、严格`<`和同一计数器的前缀/后缀`++`；循环体不能修改计数器，包括经out/inout或默认实参调用修改。`[unroll]`或`[unroll(n)]`只是提示，不改变计算次数。

每个函数的静态展开预算为4096次循环体执行，嵌套循环中的外层、内层和空循环体都计数；仍有原有绑定及调用预算。超过预算明确拒绝。上界最多为uint32最大值，最后一次实际执行时计数器小于上界，故递增不会回绕。暂不接受符号边界、while/do、break/continue、循环体return/terminal discard、非单位步长、`<=`或signed int循环。void helper自身正常return不终止外层循环，可以使用；可到达terminal discard的helper拒绝。

循环内可以使用已有struct、矩阵/数组、out/inout、默认参数、if/三元/短路、clip、纹理采样和导数。外层变量按顺序更新，每轮局部变量重新建立。逐叶初始化检查不会把未写值补成零。零次循环仍检查整个body的语法、类型、调用图和计数器保护，但没有未执行计算的定义域义务。

每次迭代保留原有完整输入场及实际执行条件。导数不获得额外线性、乘积或链式法则假设；只有输入函数和操作上下文相等，才可利用同一任意`Ops`函数的相等性。裁剪后的域要求仍按实际保留位置检查。双方所有实际计算合法仍是需要证明的结论。

`examples/complete`把纹理采样、clip、法线归一化、平方边缘光、UV矩阵、光源数组、结构体、默认参数和out数组组合起来。原版循环两次累积光照及ddx贡献；改写版手工展开两次，保留相同的完整导数输入与上下文。`wrong.hlsl`改错第二次系数；domain组区分零次循环中的非法normalize与真正执行的非法normalize。有限数值回归另有手算结果，不能替代正式证明。

```powershell
pwsh -File tools/run_demo.ps1 -Example complete
```

这组只运行核心检查，没有Unity runner。完整默认验收还包含所有旧示例。数学仍是实数加精确uint32，未引入浮点编码或新数学公理。

schema6中的`loop_semantics`和`loops`记录每个函数实际展开的区域、起止值及次数，统一校验器供Lean发射与有限求值使用。规范摘要写入生成目标字节并参与哈希绑定。元数据不充当值相等的假设，实际数学定义仍是顺序展开的计算。无循环模型不增加这些字段，旧无循环目标文字保持兼容。
